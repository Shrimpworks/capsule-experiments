# C5b15 author explanation

Review instance 1 of 3. Author testimony, not readiness verdict.

## Intent, plan and flow

C5b14B closed benign native/storage composition. The agreed next bounded task was
to reconcile that result with the immutable runner candidate before selecting the
next executable slice. This implements a small offline audit, retains source
provenance and records the remaining gates. It does not implement installed runner
identity, restart custody or a deadline remedy.

PLAN steps 1–2 and verification in step 3 are complete locally; independent review
and archive/canonical publication remain delivery work. No candidate source runs.
The verifier checks frozen materials, exact copied input hashes and relevant
internal C5b11/C5b14B evidence edges, derives fixed source facts, compares retained
report and runs 21 refusal tests. All new executable code is Node standard library.

## Component walkthrough and choices

inputs/ORIGINS.json anchors 13 files to exact repository/commit/full path/size/hash.
Its own hash is fixed in scripts/audit.mjs, so --record cannot silently bless an
input or ledger substitution. Native C/Go and former generator files are data only.
audit.mjs checks known source forms and derives root/argv/provider/profile differences,
setup-clock and teardown-gate order, and retained unresolved-restart state. It is
not a C/Go parser, platform verifier, authority service or exhaustive security scan.
README and canonical checkpoint separately provide reviewed planning judgments.

audit.test.mjs tests baseline observations, each changed input, missing/extra/redirected
inputs and false report claims. Those are audit refusal tests, not native control
restoration evidence. verify.mjs runs only the Node tests and records deterministic
facts, material hashes, tool version and test names. Ordinary mode refuses drift.
Review artifacts are excluded from material hashes to retain independent findings.

## Findings, invariants and decision rationale

The unchanged C5b14B-to-C5b11 substitution path is NO_GO because fixed root size,
argv, symbol namespace and generated profiles differ. A new versioned composition
remains BLOCKED on missing evidence; neither predecessor is abandoned.

C5b14B's cleanup deadline starts after durable teardown gate return. The local
clock therefore excludes that write's elapsed time; no initial-action bound can be
inferred from it. This is a source-order fact, not a measured stall and not a cause
assigned to the earlier unexplained setup refusal. Safe unresolved restart is
preserved but cannot be described as installed process-custody reconstruction.

Select C5b16 phase-aware timing/fault evidence next using the bounded benign fixture.
It must measure setup/publication/action/absence phases, inject finite storage delays,
preserve limits/durable gates/custody and test claims against exact clock semantics.
An eventual remedy that changes authority/durability order or architecture requires
an explicit decision gate; this slice chooses no such remedy. No new ADR needed
because no responsibility, helper, storage engine or resource policy changes.

## Verification and limitations

Local ordinary verifier passes all 13 exact inputs, internal provenance checks and
21 tests. Origin copies were extracted directly from immutable Git objects. The
canonical required check runner is completing separately; final results will be
retained before publication. Prior C5b14B native results are retained testimony and
are explicitly marked freshlyRerun=false. No guest/installed/product admission.

No package dependency; Node 22+ standard library only. Copied inputs add archive
size but avoid machine-local sibling paths or mutable web citations. There are no
new binaries or runtime artifact hashes to reproduce. Static report reproducibility
is not native artifact reproducibility. Existing raw evidence, kernel preferred-
source and cross-host workstreams retain their own scope and blockers.

## Challenge points

Check that exact input and report claims refuse tampering, source-order facts match
actual code, NO_GO applies only to the named incompatible path, remaining-gate labels
are not presented as an automated completeness proof, and C5b16 acceptance does not
invent clock anchors, widen limits, bypass durability or authorize guest execution.
The planned probe may reveal a remedy requirement; none is claimed implemented here.
