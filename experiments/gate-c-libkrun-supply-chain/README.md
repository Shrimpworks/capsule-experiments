Reproduction scripts use retained local source/build inputs under `/private/tmp` by default. They do
not submit notarization jobs, alter host trust settings, or install system software.

```sh
./run-reproducibility.sh
CAPSULE_REMAP_PATHS=true ./run-reproducibility.sh
./test-signing-flow.sh
fnm exec --using=22.22.1 -- node ./generate-sbom-input.mjs
./verify.sh
```

The first reproducibility command is expected to fail because the retained build embeds its source
directory. The path-remapped control is expected to pass on the recorded toolchain.

Retain this directory until a governed runtime build/release pipeline, source-publication bundle,
advisory intake, and signed runtime admission implementation replace it and cite equivalent or
stronger evidence. Product packages must not import these scripts.
