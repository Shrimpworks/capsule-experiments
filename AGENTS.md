# Archive contributor guide

This repository contains defensive, authorized, local-only Capsule research.
Work must remain confined to the repository, controlled local fixtures and
processes, owned disposable guests, and explicitly authorized isolated test
environments. Do not access unrelated systems, identities, credentials, or
data.

The contents are non-production experiments. Do not claim that an archived
result implements, validates, admits, or makes production-ready a Capsule
security control, runtime, backend, guest, or release profile.

When adding an experiment:

1. Record the exact question, versions, fixtures, environment, and authority
   scope.
2. Separate observed results from inference.
3. Retain positive, negative, fault, and mutation evidence where relevant.
4. Record verification, limitations, unresolved questions, and the decision.
5. Link the resulting canonical decision in `capsule-corp`; chat history is not
   retained evidence.
6. Never import this repository from Capsule product code.

Changes that alter a canonical Capsule architecture or security claim belong in
the main Capsule repository and its ADR workflow.
